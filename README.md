# BrickVerse Installer

A single Electron/TypeScript application that installs or removes the BrickVerse
Game Client and BrickVerse Creator on Windows, macOS, and Linux.

## Install directories

- Windows: `%LOCALAPPDATA%\Programs\BrickVerse` and
  `%LOCALAPPDATA%\Programs\BrickVerse Creator`
- macOS: `~/Applications/BrickVerse.app` and
  `~/Applications/BrickVerse Creator.app`
- Linux: `~/.local/share/brickverse/client` and
  `~/.local/share/brickverse/creator`

These locations are writable without administrator access.

## Development

```powershell
npm install
npm run dev
```

Build only the Windows installer:

```powershell
npm run dist:win
```

Build all packages supported by the current operating system:

```powershell
npm run dist
```

Output is written to `release/`.

## GitHub Releases / auto-update

The electron-builder publish target currently points to:

```text
BrickVerse-co/installer
```

Change `build.publish.repo` in `package.json` if the Electron installer is kept
in another repository.

Push a version tag to publish:

```powershell
npm version patch
git push
git push --tags
```

The packaged application checks GitHub Releases shortly after startup.
Windows and macOS update metadata is generated by electron-builder.

macOS automatic updates require a signed application. Configure the signing and
notarization secrets used by `.github/workflows/release.yml`.

Linux does not have the same native updater mechanism as Windows/macOS. The
AppImage build can download updates through electron-updater when GitHub release
metadata is available, while DEB installations should generally be updated by
installing the next DEB package.
